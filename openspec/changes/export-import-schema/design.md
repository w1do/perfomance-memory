## Context

Мотивация и границы — в `proposal.md` §1–2, требования — в `specs/schema-transfer/spec.md`. Полные сигнатуры, схемы
и алгоритмы лежат в `proposal.md` §6 и §8 и здесь не повторяются.

Исходные ограничения:
- вся логика — в `packages/core`, `apps/api` и `apps/web` остаются тонкими;
- запись идёт через `PreferenceService.write()`: мьютекс процесса, затем `CoalescedRefresh` (пересчёт счётчиков
  и `PREFERENCES.md`); если функция под замком бросает, обновление не запрашивается;
- дубли при обычной записи решает LLM; для чужого файла LLM использовать нельзя;
- файл кода ≤ 150 строк, оформление только из CMS.

## Goals / Non-Goals

**Goals:**
- один модуль `transfer/` в core с единицей ответственности на файл;
- предпросмотр бесплатный и безопасный, применение — идемпотентное.

**Non-Goals:**
- MCP-инструмент для импорта и экспорта (`proposal.md` §8.4);
- перенос векторов, id, снапшот Qdrant; новые env и миграции.

## Decisions

1. **Формат — JSON без служебных полей, с версией.** Альтернатива — снапшот Qdrant: тянет векторы чужой модели
   и id. Явный список полей при экспорте (не `...p`) исключает утечку служебных полей.
2. **Дедупликация без LLM, в два уровня.** Дословный ключ (формулировка, проект, полярность) считается в
   предпросмотре и при применении; смысловой (гибридный поиск и косинус ≥ 0.92) — только при применении, где
   эмбеддинги всё равно нужны. Порог строже, чем у `CONFLICT_SCORE`: ложный пропуск хуже лишнего правила, остаток
   добирает «Гигиена». Альтернатива — LLM-подтверждение: prompt-injection и стоимость.
3. **Противоположная полярность — пропуск и счётчик «противоречий».** Решить без LLM нельзя, правило получателя
   важнее чужого.
4. **Эмбеддинги вне замка, запись под замком одной функцией, которая не бросает.** Замок держится минимально, а
   обновление счётчиков запрашивается и при частичном сбое. Сбой отражается в `ImportReport`.
5. **Папки создаются пакетно, сироты убираются в `finally`.** Альтернатива — `ensurePath` на каждый путь: лишние
   `list()` и нет описаний.
6. **`source = "import"` — новое значение enum.** Индекс keyword уже есть, миграция не нужна; значение даёт
   фильтр «показать импортированное».
7. **Чекбоксы в модалке, а не в сайдбаре.** Строки сайдбара уже заняты выбором, DnD и hover-действиями.
8. **Типы пакета вынесены в `transfer/types.ts`**, чтобы `format.ts` не превысил 150 строк.

## Risks / Trade-offs

- Импортированные правила попадают в контекст агентов → предпросмотр показывает все формулировки, предупреждение
  в UI, фильтр по `source`.
- Смысловой дубль может не найтись при низком cosine → «Гигиена» после импорта.
- Длинный импорт держит замок записи до минуты → эмбеддинги вне замка, дедуп пачками по 8.
- Потолок 10 МиБ и 5000 правил → понятный отказ 413/422.
- `FakeAi.hashEmbed` — мешок слов: перестановка слов даёт тот же вектор, тест смысловых дублей на нём
  проверяет механику, а не качество порога.
