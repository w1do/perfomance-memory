# Блок инструкций для агентов без поддержки навыков

Скопируйте текст между линиями в постоянные инструкции агента: `AGENTS.md` в корне проекта или домашней папке
(Codex, Cursor, Copilot, Gemini CLI и др. читают его), правила Cursor/Windsurf/Cline, custom instructions ChatGPT,
системный промпт своего агента. MCP-сервер `preferences` должен быть подключён (см. `connect.md`).

---

## Память предпочтений пользователя (MCP-сервер `preferences`)

У пользователя есть сервис с его предпочтениями «люблю / не люблю» и жёсткими ограничениями (например,
`file_lines <= 100 lines`). Это источник правды о его вкусах — не угадывай, а спрашивай у сервиса.

1. В начале любой задачи (код, текст, план, ревью) вызови `get_context_for_task` с кратким описанием задачи
   (язык, фреймворк, тип работы, проект). Блок «Жёсткие ограничения» — обязательные требования к результату:
   оператор записан как требование (`file_lines <= 100` — каждый файл не длиннее 100 строк); проверь их перед
   сдачей. «Не люблю» — избегай, «люблю» — предпочитай. Уровень: «жёстко» — нарушение = дефект, «по умолчанию» —
   отступить можно, только назвав причину, «вкус» — мягко. «почему» и «так / не так» — ориентир в спорных местах. Одной строкой скажи, что учёл.
   Прямая просьба пользователя в текущем сообщении важнее сохранённого правила — скажи об этом.
2. Вопросы «что я люблю / мои правила / мои предпочтения по …» — `get_preferences` (фильтры `domain`, `folder`,
   `polarity`, `project`), `list_folders`, `get_folder`, `list_projects`, `get_project`. Отвечай только тем, что
   вернул сервис.
3. Пользователь высказывает долговременное предпочтение («не люблю…», «люблю, когда…», «запомни…», «всегда…») —
   `add_preference` с его фразой почти дословно (и `project`, если правило про проект); сообщи результат:
   создано / обновлено (конфликт) / дубль и папку. Разовые указания к текущей задаче не сохраняй; сомневаешься —
   спроси.
4. Сервер недоступен — скажи об этом одной фразой и продолжай без него, не выдумывая предпочтений. Токен
   `MCP_TOKEN` никогда не показывай.
