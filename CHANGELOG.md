# Журнал изменений

Все заметные изменения проекта. Формат — по датам, внутри: Добавлено / Изменено / Исправлено.

## 2026-09-25 — уровни правил, «почему», «так / не так»

### Добавлено
- Уровень правила вместо силы 1–5: «жёстко» (нарушение = дефект), «по умолчанию» (отступить можно, назвав причину),
  «вкус». Поле `level` с keyword-индексом, фильтр `level` в REST и MCP `get_preferences`, фасет; `strength` остаётся
  в payload и выводится из уровня (5 / 3 / 1). Модель определяет уровень по словам фразы. `get_context_for_task`
  отдаёт все правила «жёстко» доменов задачи и легенду уровней.
- Поля «почему» (`why`, text-индекс, входит в эмбеддинг) и пример «так / не так» (`example_good`, `example_bad`):
  модель заполняет их только со слов пользователя; видны на карточке, в MCP-ответах и PREFERENCES.md; редактируются
  в превью и редакторе; MCP `add_preference` и `pm.mjs add` принимают их явно.
- Миграция при старте api: старым правилам проставляется уровень (ограничения или сила 5 → жёстко, 1–2 → вкус,
  остальные → по умолчанию); чтение из Qdrant подставляет недостающие поля.

### Изменено
- Дубль больше не «поднимает силу», а делает уровень строже из двух и дополняет пустые «почему» и примеры.
- Интерфейс: шкала уровня вместо точек силы, выбор уровня чипами, чип фильтра «только жёсткие» вместо «сила ≥ 4».
- Навык и правила для CLAUDE.md/AGENTS.md: как агенту применять уровни и «так / не так».
- Демо-данные вынесены в `seed/demoData.ts` (файлы ≤ 150 строк).
- Правила про Claude Code в памяти переименованы: «Клауды-коды…», «ClaudeCode…» → «Claude Code…».

### Исправлено
- Деплой из GitHub с `docker-compose.yml` падал на `pull access denied for preference-memory/web`: у собираемых
  сервисов теперь `pull_policy: build` — образы собираются, а не ищутся в реестре.
- Значение `KEY=   # комментарий` из `.env` (docker compose отдаёт его как `# комментарий`) считается пустым.
- `dimensions` для эмбеддингов передаётся и моделям с префиксом провайдера (`openai/text-embedding-3-small`).
- Модель не может приписать правилу или контексту задачи проект, который пользователь не назвал: проект
  принимается, только если он есть во фразе/задаче (с учётом падежей) или передан явно; иначе правило ложится в
  тематическую папку по домену. `applies_to`, которых нет во фразе (кроме `me`, `any_ai`), отбрасываются.
- Веб: модальные окна рендерятся порталом в `<body>` — по центру экрана, поверх всего, с прокруткой содержимого и
  закреплёнными кнопками действий (раньше окно превью было зажато внутри карточки hero).
- Веб: кольцо уровня звука у кнопки микрофона больше не растягивается на всю карточку при записи.
- Веб: подзаголовок hero не рвётся по словам (токен отступа `xl` перекрывал `max-w-xl` в Tailwind 4 — введены
  отдельные токены ширины), операторы ограничений показываются без лигатур (`<=`, а не `≤`), подпись
  переключателя темы видна на мобильных (иконки луны нет на складе).
