  `icon3d`, `backdrop`, `mcp`, `motion`, `motion-run`); карточка `Card` (роли-краски, стекло, бегущая обводка,
  3D-иконка склада в углу), `Icon3D`, фон `PageBackdrop` (сияние + сетка первого экрана), подсказки `Tip` (портал),
  MCP-полоса «Подключите память к агенту» над bento с готовыми командами для Claude Code, Claude Desktop, ChatGPT и
  Cursor (только метка `<MCP_TOKEN>`) и чип MCP в шапке, карточка «Как пользоваться», шапка-стекло после прокрутки,
  макет на всю ширину (поля 44/64px), пауза анимаций на скрытой вкладке, все анимации — только без reduced motion.
- Веб, редизайн «Aurora Glass+», экран папок и модалки: `styles/folders.css` (дерево sticky слева от 1024px, до
  1024 — сворачивается; шапка папки с 3D, хлебными крошками, счётчиками и фильтрами; колонки «Люблю / Не люблю» с
  полосой полярности, от 2560 по две карточки в колонке); пустые состояния с 3D склада; `FolderTree` →

  `useDebounced` → `hooks/`. `Modal`: панель — `Card`, размеры `md`/`lg`, 3D и краска роли, размытый фон, фокус и
  `html[data-modal]`; тосты — порталом в `<body>` с цветной полосой. Подсказки `Tip` у фильтров, силы и «Проектов».
  Drag&drop, работа с папками, фильтры, поиск, редактирование и история — без изменений логики.
- Веб, редизайн «Aurora Glass+», главная: bento по областям (`styles/home.css`, пересборка от 768/1280/1920; без
  подсказок статистика занимает их место), все карточки на `Card` с 3D склада и краской роли, `McpCard` удалена (MCP —
  полоса сверху). Hero разбит на `components/capture/*` (`useCapture`, `MicButton`, `PipelineSteps` с подсказками и
  соединителями-draw, `ExampleChips`, `HeroDecor` — пол `grid-hero.svg` со сканом, `MobileMicDock` — док микрофона
  порталом на <768 с пузырём «Нажмите и говорите»); стили `styles/hero.css`, `capture/{mic,steps}.css`. Поле «…или
  напишите» — на всю ширину hero. «Папки»: реальный счёт правил и папок по дереву, если тематических папок нет —
  плитки проектов. PREFERENCES.md — тёмная карточка `card--deep` со свечением и sheen. На <640 скрытые подсказки
  возвращает кнопка под bento.
- Поиск кандидатов в конфликт: сходство = максимум из косинуса векторов и косинуса исходных фраз (противоположные
  правила лежат в разных папках «Люблю»/«Не люблю», их векторы расходятся). Порог — `CONFLICT_SCORE`.
- Обогащение: модель извлекает условие буквально («больше 100 строк» → `file_lines > 100`), требование выводит код
  (для «не люблю» оператор инвертируется → `file_lines <= 100`).
- Промпт обогащения: примеры путей из ТЗ (`ChatGPT › Не люблю` и т. п.), единицы на английском, теги без слов
  «люблю/не люблю»; промпт решения о конфликте: противоположная оценка того же аспекта — конфликт.

- Полировка по отзыву владельца: кольцо карточки на hover — одна краска роли, тонкое, без цветного ореола;
  у карточки правила нет цветной полосы слева, теги — нейтральные «пилюли», сила/путь/дата/история — одной строкой;
  в дереве нет горизонтальной прокрутки, проекты сразу под подписью «Проекты» (без дубля корня), шевроны тише;
  команды MCP переносятся вместо скролла; инструкция подключения MCP по умолчанию свёрнута.

### Исправлено
- Значение `KEY=   # комментарий` из `.env` (docker compose отдаёт его как `# комментарий`) считается пустым.
- `dimensions` для эмбеддингов передаётся и моделям с префиксом провайдера (`openai/text-embedding-3-small`).
- Модель не может приписать правилу или контексту задачи проект, который пользователь не назвал: проект
  принимается, только если он есть во фразе/задаче (с учётом падежей) или передан явно; иначе правило ложится в
  тематическую папку по домену. `applies_to`, которых нет во фразе (кроме `me`, `any_ai`), отбрасываются.
- Веб: модальные окна рендерятся порталом в `<body>` — по центру экрана, поверх всего, с прокруткой содержимого и
  закреплёнными кнопками действий (раньше окно превью было зажато внутри карточки hero).
- Веб: кольцо уровня звука у кнопки микрофона больше не растягивается на всю карточку при записи.
- Веб: подзаголовок hero не рвётся по словам (токен отступа `xl` перекрывал `max-w-xl` в Tailwind 4 — введены
  отдельные токены ширины), операторы ограничений показываются без лигатур (`<=`, а не `≤`), подпись
  переключателя темы видна на мобильных (иконки луны нет на складе).
